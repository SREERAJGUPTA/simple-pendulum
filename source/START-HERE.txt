SIMPLE PENDULUM — TIME IN MOTION

This folder includes the editable project and a complete prebuilt website.

OPEN THE PREBUILT SITE
1. Open a terminal in this folder.
2. Run: python3 -m http.server 8080 --bind 127.0.0.1 --directory docs
   On Windows with Python installed, use python in place of python3.
3. Open http://127.0.0.1:8080/ in your browser.

Use a local web server; double-clicking index.html is not supported.
The project-root index.html is the source entry. docs/index.html is the built site.
Windows-specific behavior has not been independently tested.

GITHUB PAGES
Upload the contents of this folder to the root of a new repository.
The docs/ folder is already complete; no build or file copying is needed.
In Settings > Pages, choose Deploy from a branch, select your branch,
and select /docs as the publishing folder. Save and use the URL GitHub provides.
No repository, sharing permission, or GitHub Pages configuration has been changed
on your behalf. Keep docs/assets and all generated files together.

EDIT AND REBUILD
With Node.js 22 or later and npm installed:
    npm ci
    npm run develop -- --host 127.0.0.1
For a production rebuild:
    npm test
    npm run build
The new build is in dist/. Replace the complete contents of docs/ with dist/
before publishing a changed version. README.md has detailed instructions.
